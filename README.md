# DAppCompass

DAppCompass enables hybrid decentralized applications with real-time data synchronization across smart hubs and multi-chain network transactions.

DAppCompass is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/DAppCompass.git`
2. `cd DAppCompass`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DAppCompass, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
